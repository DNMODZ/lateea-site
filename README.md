# LateEA v0508Deep — เว็บรีวิว

หน้าเว็บสาธิต (1 ไฟล์ HTML + CSS + JS + Three.js จาก CDN) สำหรับรีวิว EA กริด XAUUSD เวอร์ชัน 0508Deep

## เปิดดู

เปิด `index.html` ในเบราว์เซอร์ (ต้องมีอินเทอร์เน็ตเพื่อโหลดฟอนต์ Google Fonts + Three.js จาก CDN)

## โครงสร้าง

```
lateea-site/
├── index.html      — หน้าเดียว เนื้อหาทั้งหมด
├── css/style.css   — Anti-Spec: ไม่มีเทมเพลต AI ทั่วไป
├── js/main.js      — 3D scene (Three.js) + scroll reveal + ticker
└── README.md
```

## สิ่งที่เว็บนี้ไม่มี (ตั้งใจ) — ตรงข้ามกับ "Template SaaS/AI ทั่วไป"

| เทมเพลต AI ทั่วไป | เว็บนี้ |
|---|---|
| พื้นดำล้วน + นีออนม่วง/ฟ้า/ชมพู | พื้นเอสเพรสโซ่ `#0d0a07` + ทองเหลือง `#c8a24c` |
| Inter / Geist / sans-serif | Modern Sans-Serif: Outfit + Anuphan (ไทย) |
| h1 gradient text (bg-clip-text) | หัวข้อสีทองล้วน + คำขยาย |
| ป้าย "✨ ใหม่ 2.0" กระพริบ | ส่วน "เวอร์ชัน" เป็น changelog เนื้อหาจริง |
| Screenshot เอียง + wireframe | จำลองหน้าจอ MT5 จริง + หน้าจอ Telegram จริง |
| Bento grid 4 การ์ด + ไอคอน SVG | รายการฟีเจอร์แนวบรรณาธิการ (01–06) |
| แถบสถิติปลอม (99.9%, 10M+ users) | ไม่มี — มีข้อความ "ไม่มีตัวเลขสมมุติ" |
| Logo wall "เชื่อถือโดยทีม..." | ไม่มี |
| Blur pie circles (100px) | ฝุ่นทอง 3D (Three.js) จำนวนน้อย + แท่งทองลอย |
| glassmorphism (backdrop-blur) | ไม่มี — ขอบทองเส้นบาง + พื้นทึบ |
| ปุ่ม border หมุน/ระยิบระยับ | ปุ่มสี่เหลี่ยมทองธรรมดา hover เงาทอง |
| Grid overlay ไซเบอร์พังค์ | ไม่มี — แถบวิ่งข้อมูลจริง (ticker) |

## 3D (Three.js r128 CDN)

- แท่งทองลอย — metalness สูง หมุนตามเมาส์, ลอยขึ้นลงช้าๆ
- ฝุ่นทอง 260 อนุภาค — ไหลขึ้นช้าๆ วนรอบ
- เส้นขอบฟ้าสีทองหม่นกะพริบจางๆ
- แสง SpotLight สีอบอุ่น

ถ้าโหลด Three.js ไม่ได้ (ออฟไลน์) → เว็บยังทำงานปกติ แค่ไม่มี 3D (โค้ดเช็ค `window.THREE` ก่อน)
